# Organizational Social And Interactive Application (OSIAS)

Organizational Social and Interactive Application System is a browser-based application system which uses web technologies that is accessible on an intranet architecture. The application can be accessed using a web browser on a PC, mobile phone and etc. The application is developed using open source web technologies like HTML, CSS, typescript for the front-end and nodeJS, JavaScript and mongoDB for the back-end.

# Objectives and Purpose

The main aim of OSIAS is to offer improved communication and interactivity
within an organization in an intranet system. Also it aims are to establish secure 
inter-connectivity between individuals, and also to provide easy to use, time
effective communication and interactive system.

# Significance of Study

This research project focuses on the important functions and features of
OSIAS such as secure private and group chat, faster transmission of multimedia
files, organized file storage, enhanced and validated user identification and lastly better interface design. These functions and features within OSIAS provides so many avenues for the system to be used in many different organizations and also to be integrated into other application areas such as in schools, universities, public libraries, business offices and scientific organizations, just to mention a few. The system can be a future replacement for many intranet chat applications and other similar systems, this is because it takes less overhead, it is secure, it is fast, it is compatible and easily integrated with existing legacy system, it is better in performance in many aspects as compared to other systems and lastly it is convenient for an organization to integrate OSIAS into their existing systems.
