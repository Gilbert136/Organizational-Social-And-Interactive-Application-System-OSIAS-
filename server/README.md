# Node.js Organizational Social And Interactive Application (OSIAS)

This is an internetchat application using Node.js, Express, Passport and Mongoose. It is part of the YouTube series [here](https://www.youtube.com/watch?v=Z1ktxiqyiLA)

1.1.0

### Installation

Organizational Social And Interactive Application (OSIAS) requires :
* [Node.js](https://nodejs.org/) v4+ to run.
* [MongoDB](https://www.mongodb.com/)

```sh
$ npm install
```

```sh
$ npm start
```
